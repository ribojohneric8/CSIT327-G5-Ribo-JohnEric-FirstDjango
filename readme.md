## Description
This project is a Django web application featuring user sign-up, login/logout, and profile editing functionality styled using Bootstrap 5 via CDN.

## Features
- User Registration with success feedback messages.
- User Authentication (Login/Logout).
- Profile view and edit using Django's Class-Based `UpdateView`.
- Access control restricting profile modifications strictly to logged-in users.
- Responsive UI using Bootstrap 5 layout, navbar, forms, and alerts.
